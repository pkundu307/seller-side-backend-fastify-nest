Naming
PEP 8
Best Practices

Naming Conventions

Code is read more often than it is written. Use Snake Case for Python variables.

✅ The Python Way

user_age = 25
total_bill_amount = 450.50
is_authenticated = True

❌ Avoid These

UserAge = 25 # CamelCase (Java style)
x = 25 # Not Descriptive
1st_user = "Ram" # Starts with number
Design
Architecture

Constants

Variables that should not change. Python doesn't enforce this, but we use ALL_CAPS to signal intent.

# Database Configurations
DB_PORT = 5432
MAX_CONNECTIONS = 100
API_KEY = "sk_live_..."

# Indian Tax Example
GST_RATE = 0.18

Note: In 2025, we use `typing.Final` to strictly enforce this.

Type
Int
Data Types

Integer (int)

Whole numbers. Python integers have arbitrary precision (they can be huge).

users = 10
views = 1_500_000 # 2025 Tip: Use underscores for readability
print(views)
1500000

The underscore `_` is ignored by Python but helps engineers read large numbers (e.g., 1.5 Million).

Type
Float
Data Types

Floating Point (float)

Numbers with decimal points. Be careful: Computers struggle with decimal precision.

price = 99.99
chai_price = 15.50

# The Floating Point Error
print(0.1 + 0.2)
0.30000000000000004

Engineering Tip: For money, use the `decimal` module, never floats.

Type
Bool
Logic

Boolean (bool)

The foundation of decision making. Only two values exist.

is_active = True
is_admin = False

# Anything empty is usually "False" in Python
bool(0) # False
bool(1) # True

In Python, True is actually equal to 1 and False is 0.

Check
Type()
Validation

type()

Used to debug and check what data type a variable holds.

score = 183 # Cricket Score
player = "Virat"

print(type(score))
print(type(player))
<class 'int'>
<class 'str'>
Validate
Best Practices

isinstance() > type()

In professional code, avoid `type() == int`. Use `isinstance()` because it supports inheritance.

age = 25

# ✅ The Professional Way
if isinstance(age, int):
  print("Valid Age")

# ❌ The Beginner Way
if type(age) == int:
  print("Valid Age")
Modern
Hints
2025 Standard

Type Hints

Python is dynamic, but modern codebases use Type Hints for better IDE support and error checking.

# Variable: Type = Value
user_name: str = "Kunal"
user_age: int = 25
is_staff: bool = False

Note: This doesn't stop the code from running if types mismatch, but VS Code will warn you.

Python 3.12
PEP 695 Update

The `type` Keyword

Introduced in Python 3.12, this simplifies creating Type Aliases for complex data.

# Old Way (Pre-2024)
Vector = list[float]

# ✅ New 2025 Way
type Coordinate = tuple[float, float]

point: Coordinate = (12.5, 77.8)
I/O
Print
Output

print() Function

Sends data to the standard output (console).

print("Hello", "World")
print(1, 2, 3)
Hello World
1 2 3

Note: Comma adds a space by default.

I/O
Sep
Formatting Output

Argument: sep=""

Controls what separates multiple items in a print statement.

day = 15
month = "Aug"
year = 2025

print(day, month, year, sep="-")
15-Aug-2025
I/O
End
Formatting Output

Argument: end=""

By default, print adds a newline (`\n`). Use `end` to change this.

print("Loading", end="...")
print("Done")
Loading...Done

Useful for creating progress bars or single-line logs.

I/O
Input
User Interaction

input() Function

Pauses program execution and waits for the user to type something.

name = input("Enter your name: ")
print("Welcome", name)
Enter your name: Prasanna
Welcome Prasanna
Trap
The String Trap

Input returns Strings

input() ALWAYS returns a string, even if you type a number.

# ❌ BAD CODE
chai = input("Price: ") # User types 10
total = chai + 5 # ERROR! "10" + 5

# ✅ GOOD CODE (Type Casting)
chai = int(input("Price: "))
total = chai + 5
Format
F-Str
Modern Formatting

f-strings

Introduced in Python 3.6, perfected in 2025. The best way to format strings.

name = "Kunal"
role = "Dev"

# Put 'f' before the quote
msg = f"User {name} is a {role}"
print(msg)
User Kunal is a Dev
Logic
F-String Power

Expressions inside Strings

You can perform logic directly inside the curly braces `{}`.

a = 10
b = 20

print(f"The sum is {a + b}")
print(f"Is a greater? {a > b}")
The sum is 30
Is a greater? False
Pro
Data Science Ready

Formatting Specs

Essential for financial and scientific data presentation.

pi = 3.14159265
price = 5000

# Round to 2 decimal places
print(f"Value of Pi: {pi:.2f}")

# Add commas for currency
print(f"Laptop Price: ₹{price:,}")
Value of Pi: 3.14
Laptop Price: ₹5,000
Debug
2025 Trick

Self-Documenting f-strings

Use the `=` sign inside an f-string to print variable name AND value. Essential for debugging.

width = 50
height = 10

print(f"{width=}, {height=}")
print(f"{width * height = }")
width=50, height=10
width * height = 500
